# Read it and Weep recreation

A Next.js recreation of the interactive text canvas at [readitandweep.live](https://readitandweep.live/). It uses the original excerpt corpus, colors, typography, timing, and random placement behavior.

## Run locally

Requires Node.js 24 or newer.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verify

```bash
npm run check
```

Source inspection notes and reference screenshots are in `docs/`. The site source, text excerpts, and favicon belong to their respective creators. This repository began from [JCodesMore's AI Website Cloner Template](https://github.com/JCodesMore/ai-website-cloner-template).

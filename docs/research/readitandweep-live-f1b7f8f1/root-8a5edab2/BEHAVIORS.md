# Behaviors

- On load, the canvas starts blank, then types one random excerpt at a time.
- Text remains on screen and can overlap later excerpts.
- Each character appears on a 44.4 ms interval.
- Excerpts use random font sizes: 14–48px for widths 821–2000px and 12–24px for widths up to 820px.
- Excerpt width is 13–22 times its font size. Its fixed position is randomly chosen within the viewport based on measured text height.
- The viewport does not scroll. Resizing changes the placement area for future excerpts.
- Citation links are underlined hot pink and open their source in a new tab.
- No hover, click, or scroll state changes were found beyond normal link navigation.
